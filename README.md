# Video Reasoning Workshop — Simple Website

Minimal, static academic workshop website inspired by the AAAI-22 HC-SSL workshop.

## Publish to GitHub Pages

Upload `index.html`, `styles.css`, and the `images/` directory to the **root** of your GitHub Pages repository. Under Settings → Pages, deploy from `main` and `/(root)`. No build process is required.

## Add speaker and organizer photos

Place square or portrait JPG files into `images/` using the filenames referenced in `index.html`, e.g. `images/ali-farhadi.jpg`, `images/pritam-sarkar.jpg`. If a photo is missing, initials are shown automatically. Obtain permission where appropriate before reusing portraits.

## Edit

- `index.html`: workshop text, people, links, dates.
- `styles.css`: minimal styling and layout.
- This version does not require JavaScript. You may delete the old `script.js` from the repo.

**Important:** The provided proposal is titled *NeurIPS 2026 Workshop on Video Reasoning*, while the request concerns an ICLR workshop. The site therefore does not assert a specific confirmed conference/year. Update the header once the venue is confirmed. Speaker participation and submission details are also pending confirmation.
